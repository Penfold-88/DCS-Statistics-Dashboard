## 🛰️ What Is It?

**DCS Statistics Dashboard** is a PHP web dashboard for communities running [DCSServerBot](https://github.com/Special-K-s-Flightsim-Bots/DCSServerBot).

It provides a public-facing statistics website with:

- 🛰️ Live server information
- 👨‍✈️ Pilot statistics
- 🏆 Leaderboards
- 🛡️ Squadron pages
- 🛬 Carrier landing / LSO trap history
- 🧭 Server filters
- 🔗 Custom squadron links
- 🎨 Theme customisation
- 🌍 Multi-language groundwork
- ⚙️ Admin tools for updates, backups, privacy, SEO, and feature control

## 🧭 Recommended Starting Point

If this is your first install:

1. Read [Installation](Installation).
2. Use [Docker Deployment](Docker-Deployment) if you prefer containers.
3. Configure [API Setup](API-Setup).
4. Check [Site Features](Site-Features).
5. Customise [Themes and Branding](Themes-and-Branding).
6. Review [Security and Privacy](Security-and-Privacy).

If you are updating from an older version:

1. Read [Updates and Backups](Updates-and-Backups).
2. Back up your current install.
3. Run the updater or manually replace files.
4. Check your theme, API settings, users, and feature toggles.
