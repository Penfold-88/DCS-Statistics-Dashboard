# 🚀 V1.2 Release Notes

V1.2 is a major dashboard, admin, theme, update, language, security, and performance release.

---

## ✨ Highlights

- Full theme management system
- English, German, and Italian language support groundwork
- Expanded admin panel
- Expanded DCSServerBot API support
- Server filter selector across the frontend
- New charts and chart colour controls
- Large security hardening pass
- API caching and reduced unnecessary calls
- Demo mode support for public showcase installs

---

## 🖥️ Dashboard

- Configurable homepage cards
- Attendance cards
- Top 5 insights
- Top 5 pilot chart selector
- Leaderboard bar chart
- Pilot statistics chart improvements
- Carrier Landing / LSO data on pilot profiles
- Server cards replacing the old server table
- Custom Squadron Links menu
- Footer credits modal

---

## ⚙️ Admin

- Dashboard overview cards
- API health/debug page
- Configurable refresh rate
- Site feature controls
- Dynamic detected server controls
- Privacy & SEO page
- Settings import/export
- Update/version display improvements
- Go To Website shortcut

---

## 🎨 Themes

- Theme presets
- Custom theme colours
- Gradients
- Header image upload
- Logo support
- Chart colour controls
- Advanced CSS upload
- Theme backup and restore

---

## 🔐 Security

- CSRF protection improvements
- Session hardening
- Safer file permissions
- Safer public API config output
- Backup restore rollback protection
- Direct access blocking for generated backups and runtime data
- Optional DCSServerBot API key support
- Demo mode restrictions

---

## ⚡ Performance

- File-based API response cache
- Clear API cache button
- Avoids heavy calls when related features are disabled
- Special handling for heavy server attendance usage
- Self-hosted Chart.js
- Cache-busted assets
