# 🎨 Themes And Branding

The theme system lets each squadron customise the dashboard to match its own identity.

---

## ⚙️ Where To Configure

Go to:

```text
Admin Panel -> Settings -> Themes
```

---

## 🧭 Theme Areas

The theme page includes:

- Simple customisation
- Theme presets
- Header image
- Menu configuration
- Chart colours
- Advanced CSS upload
- Backup and restore

---

## 🌈 Colour Controls

Admins can customise colours for:

- Page background
- Header title
- Header subtitle
- Navigation
- Panels
- Cards
- Card headings
- Card text
- Muted card text
- Tables
- Table header text
- Table body text
- Player name links
- Buttons
- Footer
- Charts
- Gradients

---

## 🖼️ Header Image

The header image tab allows uploading a custom header background.

If no custom image is uploaded, the default header image is used.

Recommended size guidance is shown in the admin panel.

---

## 🪪 Logo Options

Header branding can be:

- Text only
- Logo only
- Logo and text

Recommended logo sizing is shown in the admin panel.

Allowed logo upload types:

- JPG
- PNG
- WebP

SVG uploads are not allowed for security reasons.

---

## 💾 Theme Backups

Use theme backup and restore tools before making large visual changes.

Theme backups are separate from full site settings backups.

---

## 🧰 Advanced CSS

Advanced CSS upload is for users who know CSS and want deeper customisation.

Use carefully. Bad CSS can break layout or mobile views.
